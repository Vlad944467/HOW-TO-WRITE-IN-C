Как писать цикл while:

1. Сравнение с for:
	
	//Давайте посмотрим код с for
	//и с while и сравним
	
	//КОД С FOR:
		
	for (int i = 0; i < 5; i++) {
        printf("hello");	
	}
	
	//КОД С WHILE:
		
	int i = 0;
	
	while (i < 5) {
		printf("hello\n");
	    i++
	}
	
	//Я думаю вы видите отличия:
		
2. Как использовать while:
	
	//Использовать while можно
	//по разному.
	
	//Допустим можно использовать
	//while для командной строки, я
	//уже писал как сделать командную
	//строку.
	
	//Пример:
		
    int num;

	while (1) {
        scanf("%d", &num);
        
        switch (num) {
            case 1:
            	printf("hi\n");
            	break;
            case 2:
            	printf("exit\n");
            	break;
            default:
            	printf("Unknown command\n");
            	break;	
        }
		
	}
	
	//Это конечно не совсем командная
	//строка, я просто показал для
	//примера как использовать.
	
	//Вы можете также использовать с
	//if/else.
