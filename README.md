# Как создать свою ОС (руководство)

Это репозиторий с пошаговым руководством по созданию минимальной 32-битной операционной системы для архитектуры i386.

## Что внутри

- Инструкция по установке необходимых инструментов (GCC, NASM, QEMU)
- Исходный код загрузчика на ассемблере (`boot.asm`)
- Исходный код ядра на C (`kernel.c`)
- Скрипт линковщика (`linker.ld`)
- Команды для сборки и запуска
  
## Цель

Показать базовые принципы разработки ОС: мультизагрузку, настройку стека, взаимодействие ассемблера с C, вывод в видеопамять.
